Multiple instances

37 Player's library lives inside the browser, and the browser keeps a separate storage area for each website address. So whether two copies of 37 Player share one library or have two different libraries depends on where they're running.

### Several windows or tabs, same website, same browser

Windows and tabs that open 37 Player from the same website address (for example 37dakinis.net) in the same browser all use **one and the same library**. So do the website and an installed 37 Player app in Chrome or Edge. They also share the same backup folder.

They stay in step with each other: a change made in one window — renaming a playlist, adding a prayer, deleting a track — appears in the others within a moment. If a window has a dialog open at the time, it catches up as soon as the dialog closes. So it's fine to play in one window and edit the same playlist in another, even mid-session: whatever is playing carries on, and the changes take effect when it finishes.

In the rare case that two windows change the library at almost the same instant, the second one is told its change couldn't be saved and shows the current library, so you can simply redo it — nothing is silently overwritten.

Each window plays its own audio, so playing in two windows at once means two sounds at once.

### Different browsers

Chrome, Edge, Firefox, and Safari each keep their own storage, so each has its **own separate library**, even on the same computer and at the same website address. The same goes for:

- **different browser profiles** (for example two people's profiles in Chrome);
- **private or incognito windows** — their library is also erased when the window closes;
- **different computers;**
- **a copy opened from a file**, such as **app/index.html** in the backup folder;
- **an app added to the Home Screen on an iPhone or iPad**, which is kept separate from Safari;
- **a slightly different address**, such as with or without "www", or "http" instead of "https".

Changes in one of these never appear in another.

### Moving a library from one to another

- **With a backup folder:** in the copy you want to use, choose that backup folder in setup (or Settings) and pick **Restore this backup**. The folder then belongs to that copy, and backups continue there.
- **Without one:** in the old copy use 'Import / Export' → Export, then in the new copy 'Import / Export' → Import.

Each separate library needs its own backup folder. If two of them are set to the same folder, 37 Player notices and shows **Backup paused** rather than letting them overwrite each other — see the 'Backing up' topic.
