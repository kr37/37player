Google Drive sharing test

Can people at a Center each sign in to 37 Player as themselves and share one library in a shared drive? This finds out what Google lets 37 Player see after someone picks a folder in Google's picker.

How to run it

  1. In Google Drive, make a folder for the test, ideally inside a shared drive that two of your accounts can both use (a folder in My Drive shared with the other account works too). Put any small file into it through Drive's own website, so there's something 37 Player didn't make.
  2. Here, sign in as the first account, choose that folder, and run the test, leaving what it makes.
  3. In a private window or another browser profile, do the same as the second account. Its run should find the first account's files, read them, and add to them.
  4. Copy each report and send them on.
