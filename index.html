37 Player

What it is

37 Player is a multi-platform music player and playlist creator/organizer. It was created based on years of using iTunes/Music.app in Kadampa centers - understanding that much of what iTunes does is very good, but some things can be improved for our usage.

What's better?

  • Waveform seekbar — the waveform on the 'Playing' screen shows the shape of the verses and silences in the track, so you can click straight to the right spot when you need to.
  • Side-by-side playlist editingView — the 'Edit Playlists' screen's two-pane layout makes it easy to build a playlist while browsing your library right alongside it.
  • Safety - On the main 'Playing' screen, nothing can be edited or deleted accidentally. You can set a pin to prevent access to the edit screens, if you wish.
  • Stop View — put a Stop wherever you need one in a playlist and give it a name, like "Stop for meditation." Playback pauses there and waits for a click to continue — no more prayers starting up while someone's teaching.
  • Split track — no need for Audacity. On the 'Library' tab, play a track to the point you want, click Split track, and edit the details for each half before saving them as two separate tracks.
  • Export — Export your library and playlists in a convenient, standard format for use with other players.
  • Other stuff - many things have been tweak for center use.

How to get it

If you can run this in Chrome or Edge, you'll get the very best functionality as far as keeping your library automatically backed up and easily restored.

  • Run from here. (recommended)
  • Download and run from your machine. (more complete functionality coming soon)

If you download and run locally, then choose one spot and leave it there. If you move the .html file, then it loses its library, and you'll need to re-import.
