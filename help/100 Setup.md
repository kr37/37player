Setup

The first time 37 Player opens, it asks for your language, then walks you through what matters on the device and browser you're using. For why these steps matter, see 'Reliability'.

### Choose one home for your library

Your library lives in one browser, at one address, so decide where 37 Player will live and stay with it:

- **One browser.** Chrome, Edge, Firefox and Safari each keep their own library. So do two installations of the same browser: on Linux, for example, a Flatpak Chrome and a Chrome installed from a .deb package are two separate browsers.
- **One address.** The website (37player.com) and a 37-player.html file opened from your disk are separate libraries, with separate backups.

Settings → **Library info** shows where the library you're looking at lives. To move a library somewhere else later, see 'Multiple instances'.

### Which browser

**Chrome or Edge on a computer** (Windows, Mac, Linux or Chromebook) is the best home: they keep a backup folder up to date by themselves. Most browsers built on the same engine can too; in Brave, first turn on "File System Access API" at brave://flags.

In **Firefox** or **Safari** on a computer, 37 Player works, but backups are files you save yourself. If you have Chrome or Edge, it's easiest to switch before adding anything, because a library doesn't move from one browser to another by itself. The welcome offers to copy the address so you can paste it into Chrome or Edge.

### Choose a backup folder

In Chrome, Edge and similar browsers, the welcome asks for a backup folder. Create a new, empty folder and choose it: 37 Player then keeps it up to date by itself, and also keeps a copy of 37 Player itself there (37-player.html). If your library is ever lost, open 37 Player again and choose that folder to bring everything back. In other browsers, and on phones and tablets, backups are manual. See 'Backing up'.

### iPad and iPhone: the Home Screen first

On an iPad or iPhone, Safari erases a website's data after 7 days without a visit. Added to the Home Screen, 37 Player keeps its library. The Home Screen app has a library of its own, separate from Safari's, so add it **before** importing anything. See 'Phones and tablets' for the steps.

### Android: install it as an app

On Android, the welcome offers to install 37 Player as an app (or use Chrome's ⋮ menu → Add to Home screen). Chrome then keeps the library safe rather than clearing it when space runs low. The app and the website share one library, so it can be done at any time.

### On a computer, installing is optional

In Chrome or Edge on a computer, 37 Player can also be installed as an app (the install icon in the address bar, or the ⋮ menu). It opens in a window of its own, with its own icon, and shares the website's library. Browsers are more likely to mark an installed app's storage **persistent**, protected from being cleared when the disk fills up. 37 Player asks for persistent storage every time it starts; if the browser shows a prompt about it, choose **Allow**. To check whether it's been granted, open Settings → **Library info**.

### Opening audio files with 37 Player

Installed as an app, 37 Player can open audio files from outside it:

- **On a computer** (Chrome, Edge or Brave): it's offered under **Open with** for MP3, M4A, WAV, FLAC and the other audio types. It can be made the default for a type the usual way: Default apps on Windows, Get Info → Open with → Change All on a Mac, or the file manager's settings on Linux. The first time, the browser asks once whether to allow it.
- **On Android:** it's in the **Share** menu, so a recording can be shared to it from Files, a chat, or a recorder app.

Either way, 37 Player asks: **Play it now** (in a little player of its own; the library stays as it is, and anything playing in 37 Player is paused first), **Import** (the usual import, behind the PIN), or **Play and import** (imported, then played from the Library). This isn't possible on an iPad or iPhone, in Safari on a Mac, or in Firefox.

### The new address

37 Player moved from player.37dakinis.net to **37player.com** in October 2026. Because the browser keeps a library separately for each address, a device that used the old address still has its library there. The old address shows **37 Player has moved** in the top bar, with the way across for the open library: a shared library is simply joined again at 37player.com; any other library is exported there and imported at 37player.com, or restored from its backup folder. On an iPad or phone, the Home Screen app is then removed and added again from the new address.
