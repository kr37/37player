Setup

The first time 37 Player opens, it asks for your language, then **Try it out** or **Install**. The home page (37player.com) offers the same two.

- **Try it out** starts straight away, with nothing to set up. For two days, or until your fifth import, 37 Player asks nothing about where the library is kept or about backups. Then it asks once, **Done trying it out?**, and shows the way to set it up on this device. On a computer in Safari or Firefox it first suggests Chrome or Edge, since a library doesn't move from one browser to another by itself.
- **Install** looks at the device you're using and shows only the best way to keep a library on it, a step at a time.

Wherever 37 Player isn't installed, an **Install** button stays in the top bar and opens the same steps. For why they matter, see 'Reliability'.

### Mac and Windows: the desktop app

On a Mac or a Windows computer, Install offers the **desktop app**, downloaded straight from the steps. Its library is ordinary files in a folder, it updates itself, and it doesn't ask for permission again.

The app isn't signed yet, so the computer warns the first time:

- **Mac:** open the downloaded file and drag **37 Player** into **Applications**. In Applications, Control-click (or right-click) 37 Player, choose **Open**, then **Open** again. If there's no Open button, close the warning, open **System Settings → Privacy & Security**, scroll down, and choose **Open Anyway** beside 37 Player.
- **Windows:** if the browser says the file isn't commonly downloaded, choose **…** → **Keep** (in Chrome, **Keep anyway**). When it opens, if **Windows protected your PC** appears, choose **More info**, then **Run anyway**.

A computer where apps can't be installed: choose **I can't install apps on this computer**, and the steps show the Chrome or Edge way instead.

### Other computers: Chrome or Edge

On Linux or a Chromebook (or a computer that can't install apps), 37 Player keeps its library safely only in **Chrome or Edge**. Most browsers built on the same engine can too; in Brave, first turn on "File System Access API" at brave://flags. From Firefox or Safari, the steps copy the address to paste into Chrome or Edge, and carry on there. Then:

1. **Install 37 Player** as an app from the browser (the install icon in the address bar, or the browser's menu). The installed app keeps its permission for the library's folder, and the browser doesn't clear its storage when space runs low. The steps carry on in the app's window.
2. **Keep the library in a folder:** one copy, as ordinary files, in a folder you choose. Back that folder up with the rest of the computer.
3. **A shared library,** if you like: it works well for multiple devices, and keeps a copy away from this one.

A library kept in the browser's storage can still have an automatic backup folder: Settings → **Backups**.

### iPad and iPhone: the Home Screen

On an iPad or iPhone, Safari erases a website's data after 7 days without a visit, so a Safari tab is for testing only. Added to the Home Screen, 37 Player keeps its library. The Home Screen app has a library of its own, separate from Safari's, so add it **before** importing anything; if there's already something to keep in Safari, the steps say how to bring it along. In the Home Screen app, choose Install again to finish: a shared library in Google Drive if you use it, or backups by hand, kept few. See 'Phones and tablets'.

### Android: install it as an app

On Android, Install offers to install 37 Player as an app (or use Chrome's ⋮ menu → Add to Home screen). Chrome then keeps the library safe rather than clearing it when space runs low. The app and the website share one library, so it can be done at any time. Then, as on an iPad: Google Drive, or backups by hand.

### Choose one home for your library

Your library lives in one place, so decide where 37 Player will live and stay with it:

- **One browser.** Chrome, Edge, Firefox and Safari each keep their own library. So do two installations of the same browser: on Linux, for example, a Flatpak Chrome and a Chrome installed from a .deb package are two separate browsers.
- **One address.** The website (37player.com) and a 37-player.html file opened from your disk are separate libraries, with separate backups.

Settings → **Library** shows where the library you're looking at lives: the folder or browser it's kept in, the shared library it syncs with, and where it's backed up. To move a library somewhere else later, see 'Multiple instances'.

Browsers are more likely to mark an installed app's storage **persistent**, protected from being cleared when the disk fills up. 37 Player asks for persistent storage every time it starts; if the browser shows a prompt about it, choose **Allow**. To check whether it's been granted, open Settings → **Library info**.

### Opening audio files with 37 Player

Installed as an app, 37 Player can open audio files from outside it:

- **On a computer** (Chrome, Edge or Brave): it's offered under **Open with** for MP3, M4A, WAV, FLAC and the other audio types. It can be made the default for a type the usual way: Default apps on Windows, Get Info → Open with → Change All on a Mac, or the file manager's settings on Linux. The first time, the browser asks once whether to allow it.
- **On Android:** it's in the **Share** menu, so a recording can be shared to it from Files, a chat, or a recorder app.

Either way, 37 Player asks: **Play it now** (in a little player of its own; the library stays as it is, and anything playing in 37 Player is paused first), **Import** (the usual import, behind the PIN), or **Play and import** (imported, then played from the Library). This isn't possible on an iPad or iPhone, in Safari on a Mac, or in Firefox.

### The new address

37 Player moved from player.37dakinis.net to **37player.com** in October 2026. Because the browser keeps a library separately for each address, a device that used the old address still has its library there. The old address shows **37 Player has moved** in the top bar, with the way across for the open library: a shared library is simply joined again at 37player.com; any other library is exported there and imported at 37player.com, or restored from its backup folder. On an iPad or phone, the Home Screen app is then removed and added again from the new address.
