Keyboard Shortcuts

<p>A few keys work everywhere: <kbd>Escape</kbd> closes whatever dialog is open, and <kbd>Enter</kbd> inside any dialog's text field submits it.</p>

<h3 style="margin:24px 0 8px 0;">Playing</h3>
<table style="width:100%; border-collapse:collapse; margin-bottom:20px;">
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Enter</kbd></td><td style="padding:6px 0;">Starts a track from the beginning — the highlighted one if there is one, otherwise whatever's currently queued. With another playlist open over the playing one, it starts that playlist instead: its highlighted track, or else its first.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Escape</kbd></td><td style="padding:6px 0;">Closes another playlist opened over the playing one, without changing anything.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Space</kbd></td><td style="padding:6px 0;">Toggles play/pause.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;">Double-click a track</td><td style="padding:6px 0;">Plays it immediately, stopping whatever was playing before.</td></tr>
</table>

<h3 style="margin:24px 0 8px 0;">Edit Playlists</h3>
<table style="width:100%; border-collapse:collapse; margin-bottom:20px;">
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Space</kbd></td><td style="padding:6px 0;">Toggles play/pause on the main transport.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Ctrl/Cmd</kbd>+<kbd>C</kbd></td><td style="padding:6px 0;">Copies the selected track(s), silence(s), or stop(s) from whichever pane (the playlist being edited, or the one being browsed alongside it) was last clicked into.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Ctrl/Cmd</kbd>+<kbd>V</kbd></td><td style="padding:6px 0;">Pastes the copied items into the playlist currently being edited. Audio files copied in your computer's file manager can be pasted too — into the playlist (before the first selected entry, or at the end), or on 'Library' as an import — in browsers and systems that pass copied files on to web pages; otherwise, drag them in.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Delete</kbd> / <kbd>Backspace</kbd></td><td style="padding:6px 0;">Removes the selected item(s) from the playlist being edited. Only acts there — the browse-only pane alongside it is unaffected.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>E</kbd></td><td style="padding:6px 0;">Edits the selected track, silence, or stop, in whichever pane was last clicked into. With several selected, it edits the one clicked last (marked with an amber edge); Paste goes before that one too.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>L</kbd></td><td style="padding:6px 0;">Shows the selected track(s) in 'Library': their artists and albums are selected, so the whole albums show, with the same tracks highlighted.</td></tr>
</table>

<h3 style="margin:24px 0 8px 0;">Library</h3>
<table style="width:100%; border-collapse:collapse; margin-bottom:12px;">
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Space</kbd></td><td style="padding:6px 0;">Toggles play/pause — the previewed track if one is loaded, otherwise the main transport.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Enter</kbd></td><td style="padding:6px 0;">Plays the first selected track.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Delete</kbd> / <kbd>Backspace</kbd></td><td style="padding:6px 0;">Deletes the selected track(s), with confirmation.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>↑</kbd> / <kbd>↓</kbd></td><td style="padding:6px 0;">Moves the selection within whichever list — Artists, Albums, or Tracks — was last clicked. Only when exactly one item is selected there. In Table, it goes down the table as it's shown, scrolling as it goes.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Page Up</kbd> / <kbd>Page Down</kbd></td><td style="padding:6px 0;">In Table, scrolls the list up or down a page.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>E</kbd></td><td style="padding:6px 0;">Edits the selected track(s), or renames the selected artist/album across every track that uses it.</td></tr>
</table>
<h3 style="margin:24px 0 8px 0;">The splitter</h3>
<table style="width:100%; border-collapse:collapse; margin-bottom:20px;">
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Space</kbd></td><td style="padding:6px 0;">Plays from the cursor, or pauses.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>←</kbd> / <kbd>→</kbd></td><td style="padding:6px 0;">Moves the cursor 10 milliseconds, or the selected mark if there is one. With <kbd>Shift</kbd>, 100 milliseconds; with <kbd>Ctrl</kbd> (or <kbd>Alt</kbd>), a second.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>M</kbd> / <kbd>Enter</kbd></td><td style="padding:6px 0;">Puts a mark at the cursor.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Delete</kbd> / <kbd>Backspace</kbd></td><td style="padding:6px 0;">Removes the selected mark.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>[</kbd> / <kbd>]</kbd></td><td style="padding:6px 0;">Goes to the previous or next mark, and selects it.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>,</kbd> / <kbd>.</kbd></td><td style="padding:6px 0;">Hear the two seconds up to the cursor (stopping on it), or from it.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>S</kbd></td><td style="padding:6px 0;">Moves the selected mark to the quietest moment within half a second.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>+</kbd> / <kbd>−</kbd></td><td style="padding:6px 0;">Shows less, closer, or more of the track.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Home</kbd> / <kbd>End</kbd></td><td style="padding:6px 0;">Puts the cursor at the start or the end.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Escape</kbd></td><td style="padding:6px 0;">Unselects a mark; pressed again, leaves the splitter (asking first if there are marks).</td></tr>
</table>
<h3 style="margin:24px 0 8px 0;">Edit Playlists and Library</h3>
<table style="width:100%; border-collapse:collapse; margin-bottom:12px;">
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Ctrl/Cmd</kbd>+<kbd>Z</kbd></td><td style="padding:6px 0;">Undoes the last change to tracks, playlists or folders.</td></tr>
<tr><td style="padding:6px 14px 6px 0; vertical-align:top; white-space:nowrap;"><kbd>Ctrl/Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Y</kbd></td><td style="padding:6px 0;">Redoes what was undone.</td></tr>
</table>
<p style="font-size:13px; color:var(--text-faint);">None of these are active while a dialog is open, or while typing in a text field.</p>
