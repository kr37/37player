Converter test

A trial of ffmpeg.wasm (ffmpeg compiled to run in a browser) for 37 Player: how fast it converts here, how much memory it takes, and whether converted files play without gaps. Nothing here touches your 37 Player library.

1. Load the converter

Downloads about 32 MB the first time (less if the server compresses it), then starts it.

2. Gapless check

Makes a steady tone, cuts it into three parts, converts each part, and reads them back. "Extra at start" is silence the format added that this browser didn't trim; anything above 0 can be heard as a tiny gap between tracks that should run on. Then listen: the three parts played one after another, the way 37 Player plays a playlist, should sound like one unbroken tone.

3. Convert your own files

Pick a few files: one that 37 Player can't play (WMA, Apple Lossless, compressed AIFF), a big WAV, and a long recording (an hour or two). The converted files stay on this page only. "Converter memory" is what ffmpeg itself uses; the finished file is held as well, until you leave the page.
